# setPortraitLightingOptions

[androidJvm]\
open fun [setPortraitLightingOptions](set-portrait-lighting-options.md)(options: [PortraitLightingOptions](../-portrait-lighting-options/index.md))

Set portrait lighting options.

Options see in [PortraitLightingOptions](../-portrait-lighting-options/index.md). Every field of [options](set-portrait-lighting-options.md) is applied, so the fields you leave out fall back to their defaults instead of keeping their current values.

Works only if portrait lighting is enabled. See [enablePortraitLighting](enable-portrait-lighting.md).
